🔗 Google Apps Script Web App URL

Masukkan URL Web App dari Google Apps Script kamu.
Cara mendapatkannya: Extensions → Apps Script → Deploy → Manage deployments → salin URL
Pastikan akses diatur ke Anyone.

📋 Panduan Setup Apps Script

1. Buka Google Sheets kamu → Extensions → Apps Script
2. Hapus kode yang ada, paste kode Apps Script yang sudah disediakan
3. Klik Deploy → New deployment
4. Pilih type: Web app
5. Execute as: Me
6. Who has access: Anyone (bukan "Anyone with Google Account")
7. Klik Deploy, authorize jika diminta
8. Salin URL yang muncul dan paste di field di atas
